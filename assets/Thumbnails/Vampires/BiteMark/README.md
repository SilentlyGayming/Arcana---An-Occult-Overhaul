# Vampire Birthmark — Sims 3-generated CAS thumbnails

These four **unaltered PNGs** were extracted from the user's regenerated Sims 3
`Documents/Electronic Arts/The Sims 3/Thumbnails/CASThumbnails.package` after
Arcana's independently converted bite-mark texture was loaded in CAS.

These files are actual in-game generated renders, **not** screenshots, AI art,
or copied artwork from another modder. They preserve the exact EA mannequin
camera, pose, light, and neck shape.

Resource type: `626F60CE` (256px THUM)  
Instance: `08146A9FB7FA3A0A` (EP3 VampireBirthMark CASP)  
Groups: `00000001`, `00000002`, `00000003`, `00000004`  

These are the four 256px variants present in this particular generated cache.
Group 0 and the lower-resolution 128/32 variants were **not** present in the
uploaded regenerated cache; this build does not claim to include those.

The normal Arcana `build.bat` calls `tools/package_journal.py`, which packages
these four PNGs with the two DDS texture overrides. Do not install a competing
vampire birth-mark thumbnail default replacement alongside Arcana.
